# 🖐️ HandSync - Real-Time Hand Tracking

A real-time hand tracking web application using React, TypeScript, and MediaPipe, allowing users to interact with different features through hand movements and gestures.

## 🧩 Technologies

- React
- TypeScript
- Vite
- MediaPipe Tasks Vision
- Tailwind CSS

## ✨ Features

- Real-time hand tracking and gesture detection
- Filter mode with multiple visual effects
- Piano mode triggered by finger movement
- Hand-based interaction for selecting and closing actions

## 🎮 How to use it

- Point one finger to hover over any button on the screen, then pinch to click it.
- In Filter mode, show both hands to start the filter effect, then pinch to change the filter.
- In Piano mode, show both hands and move any finger down to start a sound.
